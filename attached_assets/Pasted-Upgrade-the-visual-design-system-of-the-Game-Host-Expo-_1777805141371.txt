Upgrade the visual design system of the Game Host Expo app to feel modern, premium, playful and App Store-ready.

Do not rebuild the app.
Do not change the game logic.
Focus on visual polish, layout refinement, colour discipline, spacing, typography and component consistency.

CURRENT ISSUE
The app currently feels fun but slightly cheap due to:
- too many bright colours competing
- heavy pastel blocks
- large saturated buttons on every card
- inconsistent card colours
- cramped filter/header area
- visual hierarchy not premium enough
- game cards feel more like children’s worksheets than a modern family app

NEW DESIGN DIRECTION

The app should feel:
- premium but still fun
- calm enough for parents
- playful enough for kids
- modern App Store quality
- clean, warm, tactile, polished

Think:
- warm cream base
- deep navy typography
- soft coral as primary brand accent
- teal as secondary accent
- restrained use of game colours
- more whitespace
- less full-card colour flooding
- subtle borders and shadows
- fewer emojis in primary UI
- icons should feel consistent and intentional

-----------------------------------

Redesign the home screen to feel more premium.

- Add a small coral logo tile.

  - rounded 24

PART 9: CONSISTENCY RULES
-----------------------------------

Apply these across all screens:

- Consistent horizontal padding: 20 or 24
- Consistent card radius: 24–28

- Avoid more than 2 strong colours visible in one component
