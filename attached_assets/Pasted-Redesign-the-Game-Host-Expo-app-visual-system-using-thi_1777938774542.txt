Redesign the Game Host Expo app visual system using this direction:

“Calm Premium + Playful Accent”

Do not rebuild the app.
Do not change game logic.
Do not remove existing features.
Focus on visual design, component consistency and premium polish.

DESIGN GOAL

The app should feel:
- clean
- modern
- premium
- parent-friendly
- still playful for kids
- App Store ready

Keep:
- fresh white background
- fun colours
- friendly tone

Reduce:
- dated pastel blocks
- heavy borders
- oversized CTAs everywhere
- emoji-heavy UI
- cramped sections

Overall style:
Mostly white, spacious, calm and premium.
Use colour only as accent moments: icon tiles, badges, selected states and primary buttons.

-----------------------------------
PART 1: VISUAL RULES
-----------------------------------

Apply these rules globally:

1. Background
Use a clean white / warm white background:
- main background: #FFFCF7 or #FFFDF9
- avoid large peach panels

2. Cards
All major cards should be white.
Do not use full pastel card backgrounds except very subtly.
Cards should use:
- border radius 24–28
- subtle border #ECE6DE
- soft shadow
- generous padding

3. Colour
Use colour as accent only:
- icon tiles
- small badges
- active chips
- primary CTA
- thin accent lines

Do not flood whole cards with coral, teal, purple, blue or yellow.

4. Typography
Use deep navy for headings:
#15152B

Use muted grey-purple for secondary text:
#717184

Headings should feel bold and modern.
Body text should be readable, not tiny.

5. CTAs
Only primary journey buttons should be large and coral.
Examples:
- Start a Game
- Start Hosting
- Make a Guess

Game cards should NOT all have huge full-width coloured Play Now bars.
Use smaller refined buttons or make the whole card tappable.

-----------------------------------

Redesign the home screen with more restraint.

  - logo tile on left

Mood selector:

Game sections:

PART 8: REDUCE DATED FEEL
-----------------------------------

Apply these clean-up rules:

- Reduce emoji use in headings and buttons.
- Use icons where possible.
- Avoid italic microcopy if it makes the UI feel dated.
- Avoid heavy outlines.
- Avoid too many pill badges in one row.
- Avoid bright orange being repeated too often.
- Increase whitespace between sections.
- Make hierarchy obvious:
  1. What should I do now?
  2. What game is this?
  3. What details do I need?
