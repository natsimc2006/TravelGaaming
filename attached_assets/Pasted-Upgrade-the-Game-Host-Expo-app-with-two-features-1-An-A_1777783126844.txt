PART 4: GAME-SPECIFIC AI PROMPT LOGIC
-----------------------------------

WHAT AM I?
AI prompt format must include:
- answer
- acceptedAnswers
- 5 clues
- difficulty
- ageRange
- tags

Rules:
- Clue 1 should be broad
- Clue 2 should narrow it
- Clue 3 should include a useful trait
- Clue 4 should be easier
- Clue 5 should almost give it away
- Answer must be family-safe and common enough for the age group

Example:
Answer: “Umbrella”
Clues:
1. I am useful when the weather changes.
2. People usually carry me outside.
3. I open up above your head.
4. I help keep rain off you.
5. I have a handle and a canopy.

ALPHABET SHOWDOWN
AI prompt format:
- category
- optional theme
- suitable letters
- tags

Examples:
- “Things you might find in a messy car”
- “Animals that would make terrible passengers”
- “Foods that are hard to eat in the back seat”

CATEGORY DASH
AI prompt format:
- letter
- 5 categories
- tags

Categories should be broad enough to answer but specific enough to be fun.

FORBIDDEN WORD
AI prompt format:
- targetWord
- forbiddenWords
- difficulty
- ageRange
- tags

Rules:
- forbidden words must make the card challenging but possible
- avoid brand names
- avoid adult themes
- keep language simple
